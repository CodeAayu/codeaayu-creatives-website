# CodeAayu Creatives

A kinetic, scroll-led photography portfolio for Aayush Ahuja. The experience combines the restraint of a fine-dining studio with warm portrait energy, layered contact sheets, field photography, and a dedicated lunar chapter.

## Creative direction

- **Studio atmosphere:** deep plum, warm ivory, vermilion, butter yellow, and lunar blue
- **Typography:** Instrument Serif with DM Sans
- **Motion:** CSS 3D photo stacks, scroll-driven lunar studies, kinetic type, subtle pointer depth, and draggable film frames
- **Voice:** welcoming, confident, lightly playful, and never over-produced
- **Photography:** a curated, web-optimized selection from the local `Final Edits` archive

## Experience map

1. Hero portrait of Aayush actively shooting
2. Studio promise: less posing, more living
3. Scroll-controlled “memory machine” contact sheet
4. Portrait, celebration, and brand tasting menu
5. Draggable joyful portrait filmstrip
6. Wildlife and landscape field notes
7. Scroll-driven moon room and Milky Way interlude
8. Personal introduction, working process, and booking form
9. A filterable full gallery with every Final Edits photograph plus selected Kajal and Sansruti campaign work

## Local preview

The site is intentionally framework-free and works directly from static files.

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080`.

## Validation build

```bash
npm run build
```

The build packages the static site and its selected imagery into `dist/server/public`, with a Cloudflare Worker-compatible entrypoint at `dist/server/index.js` for OpenAI Sites. The repository root remains compatible with GitHub Pages and the existing custom domain.

The booking form posts to Web3Forms and provides a direct email fallback if submission fails. Motion honors `prefers-reduced-motion`; the navigation, gallery lightbox, accordions, and form remain keyboard accessible.

The gallery manifest is generated by `scripts/import_gallery.py`. It currently contains 175 frames: 156 from `Final Edits`, 8 selected Kajal portraits, and 11 selected Sansruti campaign frames. Each photograph has a lightweight grid image and a higher-resolution lightbox image. The importer removes obsolete generated assets and requires a reviewed, descriptive title for every `Final Edits` photograph, so the published archive stays aligned with the source folder.
